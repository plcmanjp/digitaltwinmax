설비 모델에 PLC 신호를 연결하세요.

설비 3D 모델에 센서와 구동부를 붙이고, 구동 값과 I/O 주소를 설정하는 Windows 앱입니다. 가상 신호로 먼저 움직여 보고, PLC 제어 프로그램과 연결해 설비의 반응을 시험합니다.

기능과 설정 보기 체험판 받기

제품판은 STEP 파일(.step, .stp)을 바로 불러옵니다. 무료 체험판은 미리 설정된 MINI MPS 장비로 시작합니다.

사용 흐름

모델을 준비하고,동작과 신호를 설정합니다.

형상은 CAD에서 준비합니다. 앱에서는 어느 부품을 어떻게 움직이고, 어떤 신호에 반응하게 할지 설정합니다.

  1. 01

    STEP 파일을 엽니다

    설계한 설비의 STEP 파일을 앱에서 바로 엽니다. 부품 트리와 3D 화면에서 구조를 확인하고, 구동할 부품과 센서를 배치할 위치를 선택합니다.

    지원 형식: STEP (.step, .stp). 체험판에서는 제공된 MINI MPS 장비를 사용합니다.

  2. 02

    부품에 동작을 붙입니다

    오브젝트에 센서나 구동부 컴포넌트를 할당합니다. 속성 패널에서 구동 거리 같은 동작 값과 I/O 주소를 설정하므로, 앱 안에서 별도의 동작 스크립트를 작성하지 않습니다.

    화면 예시: 실린더 전진 거리 55mm, A/B 밸브 출력 Y1과 Y2.

  3. 03

    신호를 연결해 시험합니다

    PLC 연결 전에는 가상 실행과 신호 시뮬레이터로 설비의 반응을 확인합니다. PLC 제어 프로그램으로 시험할 때는 대상에 맞는 통신 방식과 접속 값을 설정하고, 구동부와 센서의 I/O를 연결합니다.

    화면 예시: MX Component와 논리 국번 설정. PLC 제어 프로그램과 통신 환경은 별도로 준비합니다.

각 화면을 누르면 설정 항목을 크게 볼 수 있습니다. PLC 통신 이미지는 설정 화면이며, 하드웨어 연결 시연은 아닙니다.

특징과 활용

모델, 동작, 신호를함께 봅니다.

어느 부품이 어떤 신호에 반응하는지, 기계 설계와 PLC 제어를 같은 설비 화면에서 대조합니다.

설계한 모델을 이어서 사용
설계한 설비의 STEP 파일을 가져옵니다. 불러온 모델을 바탕으로 구동 대상과 센서, 입출력 관계를 구성합니다.
구동 조건은 속성 패널에서
앱의 구동 설정은 컴포넌트와 속성 패널에서 처리합니다. 실린더의 이동 거리와 밸브 주소처럼 엔지니어에게 익숙한 값으로 설정합니다.
신호와 움직임을 함께 확인
I/O 주소를 부품의 동작과 연결합니다. 그 신호가 설비의 어느 부분에 대응하는지 3D 화면과 함께 살펴봅니다.
PLC 연결 전부터 시작
모델과 컴포넌트를 준비한 뒤 가상 실행으로 먼저 확인합니다. PLC 제어 시험 단계에서는 통신 설정과 입출력 매핑을 이어서 다룹니다.

PLC와 가상 설비가 주고받는 것

PLC 출력밸브와 구동 명령→가상 구동부설정한 조건에 따라 동작

가상 센서설비 안의 감지 상태→PLC 입력제어 프로그램에서 사용

컴포넌트의 포트와 PLC 주소를 매핑해 연결합니다. PLC 프로그램은 기존 개발 환경에서 준비합니다.

기계 설계 검토에

구동할 부품을 고르고 이동 거리를 설정해 보세요. 설비 모델을 함께 보면서 센서 위치와 동작 순서를 설명할 때 사용할 수 있습니다.

자주 묻는 질문

사용 전에 알아둘 것

어떤 설비 모델을 불러올 수 있나요?

제품판은 STEP 파일(.step, .stp)을 앱에서 바로 불러옵니다. CAD에서 준비한 설비 모델을 열고, 부품별로 동작과 신호 설정을 이어갑니다. 체험판은 모델 가져오기 대신 미리 설정된 MINI MPS 장비를 제공합니다.

“코드리스”는 어느 작업을 뜻하나요?

앱 안에서 센서와 구동부의 동작을 설정하기 위해 별도의 스크립트를 작성하지 않는다는 뜻입니다. 컴포넌트를 할당하고 속성 값과 I/O 주소를 입력합니다. PLC로 시험할 때 사용할 래더 등 제어 프로그램은 별도로 준비합니다.

PLC가 없어도 먼저 확인할 수 있나요?

가상 실행과 신호 시뮬레이터로 설비의 움직임을 먼저 살펴볼 수 있습니다. 이 페이지의 MINI MPS 동작 영상도 실제 하드웨어 PLC에 연결하지 않은 모의 실행입니다.

PLC로 시험하려면 무엇이 필요한가요?

시험할 PLC 제어 프로그램, 통신 환경, 센서와 구동부의 I/O 매핑을 준비합니다. 소개 화면의 MX Component 방식은 해당 통신 환경과 논리 국번 설정이 필요합니다. 체험판은 MINI MPS의 I/O 매핑이 미리 설정되어 있으므로 래더 작성과 통신 설정을 준비하면 됩니다. 필요한 환경은 아래 체험판 안내를 확인하세요.

체험판에 샘플 래더가 들어 있나요?

들어 있지 않습니다. 체험판은 센서와 구동부, I/O 주소가 미리 설정된 MINI MPS 장비를 제공하고, 래더는 사용자가 GX Works2에서 직접 작성합니다. 직접 짠 제어 프로그램에 설비가 어떻게 반응하는지 바로 시운전해 보는 것이 체험의 목적입니다.

체험판에서 하는 일

  • 센서와 구동부 디바이스, I/O 주소까지 미리 설정된 MINI MPS 튜토리얼 장비를 엽니다.
  • 샘플 래더는 제공하지 않습니다. GX Works2에서 직접 작성한 래더로 장비를 움직여 시험 시운전합니다.
  • 제공된 장비의 설정을 바꿔 저장하고 다시 열 수 있습니다.
  • 임의의 STEP 모델 가져오기와 새 설비 만들기는 제품판 기능이며, 체험판에서는 사용할 수 없습니다.

필요한 환경

  • Windows PC. 지원하는 Windows 버전과 사양은 릴리스 노트에서 안내합니다.
  • 미쓰비시 GX Works2와 MX Component가 설치된 환경. MX Component는 체험판에 포함되지 않으며, 이미 설치해 사용 중인 것을 그대로 씁니다.
  • 대상 PLC는 미쓰비시 Q 시리즈입니다. GX Works3(FX5, iQ-R)는 이번 체험판에서 지원하지 않습니다.
  • 연결 대상은 GX Simulator2와 실제 Q PLC(USB, Ethernet)입니다. 확인을 마친 연결 경로는 릴리스 노트에 표시합니다.

내려받기 전 확인

  • 체험판 파일에는 코드 서명이 없어 Windows가 경고를 표시할 수 있습니다.
  • 이 페이지와 연결된 공식 Releases에서 받은 파일만 실행하세요. 다른 곳에서 받은 파일은 사용하지 마세요.
  • 릴리스 노트의 SHA-256 해시와 내려받은 파일의 해시가 같은지 확인하세요. PowerShell에서는 Get-FileHash 파일경로로 확인할 수 있습니다.
  • 실제 PLC로 시험할 때는 출력에 설비가 연결되지 않은 시험용 환경에서 진행하세요.

체험 후 의견

  • 체험판을 종료할 때 설문 참여 여부를 묻습니다. 참여를 고르면 Google Form이 열리며, 참여는 선택입니다.
  • 앱이 실행되지 않거나 도중에 막혔다면 체험판 설문 (새 탭)에서 바로 알려 주세요.
  • 앱의 데이터, PLC 주소, 파일은 자동으로 전송되지 않습니다. 설문은 Google 로그인 없이 응답할 수 있고, 이메일은 후속 연락에 동의한 경우에만 직접 입력합니다. 원본 응답은 수집일부터 90일 동안 보관한 뒤 삭제합니다.
  • 버그와 기능 제안은 공개 GitHub Issues (새 탭)에 남겨 주세요. 공개 게시판이므로 개인정보, 연락처, 고객 도면, PLC 네트워크 주소는 올리지 마세요.
