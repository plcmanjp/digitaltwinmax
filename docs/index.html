내가 짠 래더로움직이는 3D 설비

장비를 조립하기 전에, GX Works2에서 작성한 래더 프로그램으로 3D 설비 모델의 공급부터 분류까지 시운전합니다.

WORKFLOW & VALUE

장비를 기다리지 않고 세 단계로 시운전합니다

조립과 배선이 끝나기 전에 책상 위 PC에서 동작 순서와 센서 조건을 먼저 검증합니다.

  1. 01

    조립이 끝나기 전에 시작합니다

    3D 설비 모델이 있으면 장비가 제작되는 동안 제어 프로그램을 먼저 돌려 보며 현장 시운전 부담을 줄입니다.

  2. 02

    장비 파손 없이 반복 시험합니다

    잘못된 출력에도 가상 설비는 부딪히거나 망가지지 않습니다. 센서 누락과 인터록 조건을 몇 번이든 검증합니다.

  3. 03

    PC 한 대로 실습과 검토를 함께

    실물 교육 장비가 부족한 현장에서도 PC 한 대로 래더 신호와 3D 기구 반응을 동시에 관찰할 수 있습니다.

  1. STEP 01

    설비 구조를 트리와 3D로 파악합니다

    제품판에서는 설계한 STEP 파일(.step, .stp)을 바로 열고, 무료 체험판에서는 내장된 MINI MPS 장비로 부품 트리와 3D 뷰포트를 바로 확인합니다.

    • 358부품 계층 트리
    • 3D 뷰포트 강조
    • 좌표 및 역할 속성

  2. STEP 02

    스크립트 없이 행정 거리와 I/O를 입력합니다

    선택한 부품에 실린더나 센서 컴포넌트를 붙이고, 전진 거리(mm)와 밸브/센서 PLC 주소를 속성 패널에 입력합니다.

    • 전진 55 mm
    • 밸브 출력 Y10 / Y11
    • 도착 센서 X10 / X11

  3. STEP 03

    가상 실행부터 미쓰비시 PLC 연동까지

    내장 신호 시뮬레이터로 동작을 먼저 점검하고, 통신 설정에서 MX Component 또는 MC 프로토콜을 지정해 제어 프로그램과 연결합니다.

    • 내장 가상 PLC
    • MX Component 논리 국번
    • 이더넷 MC 프로토콜

MINI MPS는 체험판에 내장된 튜토리얼용 교육 장비입니다. 공급 매거진과 이송 적재 장면을 나란히 살펴보세요.

01 공급 매거진 02 이송과 적재 주요 시점 스틸 3장

주요 시점 스틸 화면 (공급부, 이송과 적재, 위에서 본 배치)

공급부

매거진에서 나온 워크가 컨베이어로 넘어갑니다.

이송과 적재

은색 워크는 진공 패드로 집어 초록 적재함에 놓고, 주황 워크는 슈트를 따라 빨간 배출 통으로 내려갑니다.

위에서 본 배치

동작 영상과 스틸 화면은 실제 PLC 없이 내장 가상 PLC로 촬영했습니다.

필요한 환경

  • Windows 10 또는 11(64비트) PC. 가상 실행과 기본 조작은 추가 프로그램 없이 바로 시작합니다.
  • PLC 연동 시: GX Works2와 MX Component가 설치된 환경(MX Component는 체험판에 포함되지 않음), 또는 이더넷 MC 프로토콜 연결 환경.
  • 지원 PLC: 미쓰비시 Q 시리즈. GX Simulator2 또는 실제 Q PLC에 연결하며, GX Works3(FX5, iQ-R)는 지원하지 않습니다.

다운로드 전 확인

  • 실행할 때 Windows 보호 창(SmartScreen)이 표시될 수 있습니다. 위 릴리스 노트의 해시를 먼저 대조한 뒤 추가 정보에서 실행을 선택하세요.
  • 릴리스 노트의 SHA-256 해시와 다운로드한 파일의 해시가 같은지 확인하세요. PowerShell에서는 Get-FileHash 파일경로로 확인할 수 있습니다.
  • 실제 PLC로 시험할 때는 출력에 설비가 연결되지 않은 시험용 환경에서 진행하세요.

체험 후 의견

  • 앱이 실행되지 않거나 도중에 막혔다면 체험판 설문 (새 탭)에서 알려 주세요.

  • 이 프로그램은 설문 응답, 프로젝트 파일, 사용 기록을 자동으로 전송하지 않습니다.
  • 버그와 기능 제안은 공개 GitHub Issues (새 탭)에 남겨 주세요. 공개 게시판이므로 개인정보, 연락처, 고객 도면, PLC 네트워크 주소는 올리지 마세요.

FAQ

사용 전에 알아둘 것

어떤 설비 모델을 불러올 수 있나요?

제품판은 STEP 파일(.step, .stp)을 바로 불러옵니다. 체험판은 내장된 MINI MPS 교육 장비를 제공합니다.

어떤 PLC를 지원하나요?

미쓰비시 Q 시리즈입니다. MX Component로 GX Simulator2 또는 실제 Q PLC에 연결하며, 이더넷은 MC 프로토콜로도 연결할 수 있습니다. 검증을 마친 연결 경로는 릴리스 노트에 표시합니다.

PLC가 없어도 먼저 확인할 수 있나요?

네. 가상 실행과 신호 시뮬레이터로 설비의 움직임을 먼저 볼 수 있습니다.

AI 에이전트와 함께 쓸 수 있나요?

MCP를 지원하는 외부 AI 에이전트가 설비 구성과 PLC 신호를 조회할 수 있습니다. 에이전트가 낸 편집안을 앱에서 사람이 승인해 적용하는 기능은 개발 중입니다.

체험판에 샘플 래더가 들어 있나요?

들어 있지 않습니다. GX Works2에서 직접 작성한 래더로 MINI MPS를 시운전해 보는 것이 체험의 목적입니다.

Windows 보호 창(SmartScreen)이 뜨면 어떻게 하나요?

초기 체험판에는 코드 서명이 적용되어 있지 않아 Windows 보호 창이 표시될 수 있습니다. 릴리스 노트의 SHA-256 해시와 내려받은 파일의 해시가 같은지 먼저 확인한 뒤 실행하세요.

제품판은 어떻게 쓸 수 있나요?

제품판의 제공 시기와 조건은 아직 안내하지 않습니다. 도입 문의는 digitaltwinmax@googlegroups.com으로 보내 주세요.
