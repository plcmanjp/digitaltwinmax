체험판 받기 기능 보기

FUNCTIONS

모델에서 시험까지.

설비 모델을 불러오고, 컴포넌트를 할당한 뒤,
PLC로 가상 환경에서 시험합니다.

  1. 01

    모델을 불러오기

    실제 설비의 CAD로 만든 3D 모델을 불러옵니다. 형상은 부품 트리에 올라오고, 배치를 확인한 뒤 프로젝트에 저장합니다.

  2. 02

    컴포넌트를 할당하기

    오브젝트에 센서와 구동부 같은 컴포넌트를 붙여 움직임을 정합니다. 입력과 출력은 그 컴포넌트에 설정합니다.

  3. 03

    PLC로 시험하기

    통신을 설정하면 PLC가 상위 제어기가 되어, 가상 환경에서 설비를 시험합니다. 연결 전에는 신호 시뮬레이터로 같은 흐름을 먼저 볼 수 있습니다.

실제 앱에서 촬영한 가져오기, 컴포넌트 설정, 통신 설정 화면입니다. 실제 PLC를 통한 설비 동작 시험 결과나 체험판 파일 공개를 뜻하지 않습니다.

SCENES

같은 샘플, 다른 장면.

배치와 정면, 그리고
가까이서 본 동작입니다.

위 시점

위에서 보면 컨베이어, 매거진, 조작 버튼의 배치가 한 평면에 보입니다.

정면, 가상 실행

정면으로 바꾼 뒤 가상 실행을 시작한 화면입니다. 실제 장비에는 연결하지 않았습니다.

공급 확대

매거진에서 적재물이 나와 컨베이어로 넘어가는 장면입니다.

적재 확대

이송부가 제품을 집어 적재함으로 옮기는 장면입니다.

부품 선택

트리에서 고르면 3D와 속성 패널이 함께 따라옵니다.

화면은 앱을 실행해 찍은 것이며, 전체 기능의 완료나 체험판 파일 공개를 뜻하지 않습니다.

MOTION

샘플이 움직이는 장면.

동작이 보이는 기록만 골랐습니다.
장면을 골라 바로 볼 수 있습니다. 실제 장비에는 연결하지 않았습니다.

영상을 준비하는 중입니다.

무음 영상이며 재생 버튼으로 시작합니다. 화면의 PLC는 모의 상태입니다.
