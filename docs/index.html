DigitalTwinMax.

설비의 3D 모델을 띄우고,
연결 없이 가상으로 돌려 보는 Windows 앱입니다.

체험판 받기 기능 보기

FUNCTIONS

화면에서 하는 일.

같은 샘플로 시점을 바꾸고,
부품을 고른 뒤 가상으로 실행합니다.

  1. 01

    시점을 바꾸기

    같은 설비를 등각, 위, 정면으로 봅니다. 위 시점에서는 컨베이어, 매거진, 조작 버튼의 배치가 한 평면에 놓입니다.

  2. 02

    부품을 고르기

    부품 트리에서 고르면 3D에서 그 묶음이 강조됩니다. 오른쪽 속성에는 이름과 위치가 따라옵니다.

  3. 03

    가상으로 실행하기

    실제 장비에 연결하지 않고 샘플 공정을 재생합니다. 아래 신호 시뮬레이터의 값이 함께 바뀌며, 화면의 PLC는 모의 상태입니다.

화면은 앱을 실행해 찍은 것이며, 전체 기능의 완료나 체험판 파일 공개를 뜻하지 않습니다.

SCENES

같은 샘플, 다른 장면.

배치와 정면, 그리고
가까이서 본 동작입니다.

위 시점

위에서 보면 컨베이어, 매거진, 조작 버튼의 배치가 한 평면에 보입니다.

정면, 가상 실행

정면으로 바꾼 뒤 가상 실행을 시작한 화면입니다. 실제 장비에는 연결하지 않았습니다.

공급 확대

매거진에서 적재물이 나와 컨베이어로 넘어가는 장면입니다.

적재 확대

이송부가 제품을 집어 적재함으로 옮기는 장면입니다.

부품 선택

트리에서 고르면 3D와 속성 패널이 함께 따라옵니다.

화면은 앱을 실행해 찍은 것이며, 전체 기능의 완료나 체험판 파일 공개를 뜻하지 않습니다.

MOTION

샘플이 움직이는 장면.

동작이 보이는 기록만 골랐습니다.
장면을 골라 바로 볼 수 있습니다. 실제 장비에는 연결하지 않았습니다.

영상을 준비하는 중입니다.

무음 영상이며 재생 버튼으로 시작합니다. 화면의 PLC는 모의 상태입니다.
