설비 모델에 PLC 신호를 연결하세요.

장비를 조립하기 전에, 3D 설비 모델로 PLC 제어 프로그램을 시운전합니다.

기능 보기 체험판 받기

Windows 앱입니다. 제품판은 STEP 파일을 바로 불러오고, 무료 체험판은 내장된 MINI MPS 교육 장비로 시작합니다.

기능

설비 모델 하나로시운전까지.

스크립트 없이, 엔지니어에게 익숙한 값으로 설정합니다.

STEP 불러오기
설계한 설비의 STEP 파일을 바로 엽니다(제품판).
센서와 구동부 할당
부품에 실린더, 센서 같은 컴포넌트를 붙입니다.
I/O 주소 매핑
구동 거리와 PLC 주소를 속성 패널에 입력합니다.
가상 실행
PLC 없이 신호 시뮬레이터로 설비 반응을 먼저 봅니다.
미쓰비시 PLC 연결
MX Component로 GX Simulator2와 Q 시리즈에 연결합니다.
저장과 다시 열기
설정한 프로젝트를 저장해 다음 검토에 다시 씁니다.

PLC와 디지털트윈맥스가 주고받는 것

PLC래더 등 제어 프로그램

출력 밸브와 구동 명령, PLC에서 디지털트윈맥스로

입력 센서의 감지 상태, 디지털트윈맥스에서 PLC로

디지털트윈맥스3D 가상 설비, 구동부 동작과 센서 감지

구동부와 센서의 포트를 PLC 주소에 매핑하면 신호가 오갑니다. PLC 프로그램은 기존 개발 환경에서 준비합니다.

사용 흐름

세 단계로설정합니다.

형상은 CAD에서, 동작과 신호는 앱에서 설정합니다.

  1. 01

    STEP 파일을 엽니다

    설비 모델을 열고 부품 트리와 3D 화면에서 구조를 확인합니다.

  2. 02

    부품에 동작을 붙입니다

    컴포넌트를 할당하고 구동 거리와 I/O 주소를 입력합니다.

  3. 03

    신호를 연결해 시험합니다

    가상 실행으로 먼저 확인하고, 통신을 설정해 PLC 제어 프로그램과 연결합니다.

자주 묻는 질문

사용 전에 알아둘 것

어떤 설비 모델을 불러올 수 있나요?

제품판은 STEP 파일(.step, .stp)을 바로 불러옵니다. 체험판은 내장된 MINI MPS 교육 장비를 제공합니다.

“코드리스”는 어느 작업을 뜻하나요?

센서와 구동부의 동작을 스크립트 없이 컴포넌트와 속성 값으로 설정한다는 뜻입니다. 래더 등 PLC 제어 프로그램은 별도로 준비합니다.

PLC가 없어도 먼저 확인할 수 있나요?

네. 가상 실행과 신호 시뮬레이터로 설비의 움직임을 먼저 볼 수 있습니다.

PLC로 시험하려면 무엇이 필요한가요?

PLC 제어 프로그램, 통신 환경, 센서와 구동부의 I/O 매핑이 필요합니다. 체험판은 I/O 매핑이 미리 설정되어 있어 래더와 통신 설정만 준비하면 됩니다.

체험판에 샘플 래더가 들어 있나요?

들어 있지 않습니다. GX Works2에서 직접 작성한 래더로 MINI MPS를 시운전해 보는 것이 체험의 목적입니다.

체험판

직접 짠 래더로 시운전해 보세요

신청 없이 바로 내려받는 무료 체험판입니다. 사용 기한이 없습니다.

공식 배포

공식 공개 소식 확인

체험판의 공개 여부와 배포 파일은 공식 Releases 목록에서 확인할 수 있습니다.

공식 Releases ↗ (새 탭)

체험판에서 하는 일

  • I/O 주소까지 설정된 MINI MPS 장비로 시작합니다.
  • 래더는 GX Works2에서 직접 작성합니다. 샘플 래더는 없습니다.
  • 설정을 바꿔 저장하고 다시 열 수 있습니다. STEP 가져오기는 제품판 기능입니다.

필요한 환경

  • Windows PC. 버전과 사양은 릴리스 노트에서 안내합니다.
  • GX Works2와 MX Component가 설치된 환경. MX Component는 체험판에 포함되지 않습니다.
  • 미쓰비시 Q 시리즈. GX Simulator2 또는 실제 Q PLC(USB, Ethernet)에 연결하며, GX Works3(FX5, iQ-R)는 지원하지 않습니다.

내려받기 전 확인

  • 체험판 파일에는 코드 서명이 없어 Windows가 경고를 표시할 수 있습니다.
  • 이 페이지와 연결된 공식 Releases에서 받은 파일만 실행하세요.
  • 릴리스 노트의 SHA-256 해시와 내려받은 파일의 해시가 같은지 확인하세요. PowerShell에서는 Get-FileHash 파일경로로 확인할 수 있습니다.
  • 확인을 마친 연결 경로는 릴리스 노트에 표시합니다.
  • 실제 PLC로 시험할 때는 출력에 설비가 연결되지 않은 시험용 환경에서 진행하세요.

체험 후 의견

  • 체험판을 종료할 때 선택형 설문 참여 여부를 묻습니다.
  • 앱이 실행되지 않거나 도중에 막혔다면 체험판 설문 (새 탭)에서 알려 주세요.
  • 앱의 데이터, PLC 주소, 파일은 자동으로 전송되지 않습니다. 설문은 Google 로그인 없이 응답하며, 이메일은 후속 연락에 동의한 경우에만 직접 입력합니다. 원본 응답은 수집일부터 90일 동안 보관한 뒤 삭제합니다.
  • 버그와 기능 제안은 공개 GitHub Issues (새 탭)에 남겨 주세요. 공개 게시판이므로 개인정보, 연락처, 고객 도면, PLC 네트워크 주소는 올리지 마세요.
